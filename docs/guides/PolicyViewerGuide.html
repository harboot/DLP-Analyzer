Policy Viewer Guide

Validate and review extracted Forcepoint DLP policy JSON files.

Features

  • Validates extracted policy JSON files and records accepted files, schema problems, and parsing errors in a load log.
  • Combines policy, rule, classifier, severity action, source, destination, channel, and exception details in a searchable table.
  • Summarizes blocking, disabled, and exception-bearing rules, supports hiding disabled rules, and exports the filtered view to CSV.

Quick start

  1. Select Upload Policy (JSON) and choose one or more JSON files produced by Forcepoint DLP policy extraction. Each file must contain a policy object and policy.rules, severity_action.rules, and source_destination.rules arrays. A new selection replaces the previous selection.
  2. The load log identifies accepted files and schema or parsing errors. Search and filter columns to focus on policies, rules, classifiers, actions, sources, channels, or exceptions.

Review status

Use the counters and Hide Disabled control to distinguish blocking, disabled, and exception-bearing rules. Expand exception details where available.

Export

Export CSV (filtered) saves the currently filtered rows without exception details. All parsing stays in your browser.
