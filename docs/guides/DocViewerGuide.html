Document Viewer Guide

Inspect unknown or misleading file types without uploading them to a server.

Features

  • Detects common text, document, archive, PDF, and image formats from file contents when possible instead of relying only on the extension.
  • Shows file metadata and magic bytes, extracts searchable text from supported documents, and renders supported pages or images.
  • Lists ZIP entries and lets you inspect supported archive content without sending the file to an application server.

Quick start

  1. Select or drop one file. The viewer recognizes common text, Office, OpenDocument, PDF, ZIP, and image formats from file contents when possible.
  2. File info shows size, detected type, magic bytes, and preview source. Archives show their entries; supported documents expose extracted text, pages, or an embedded preview.

Search extracted text

Enter a keyword in Search to locate matching text. Restore initial returns from a selected archive entry or alternate preview to the first automatic view.

Clear sensitive data

Select Clear before choosing another document. Processing occurs locally in your browser, but browser-supported preview behavior varies by file type.
