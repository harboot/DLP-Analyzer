Keyword Generator Guide

Generate efficient keywords from document subjects or document content.

Quick start

  1. Use Document Subject for one subject per line and set-cover ranking. Use Document Content for longer text scored by frequency, phrase length, and context.
  2. Enter one exact exception per line. Prefix a phrase with + to require it, or with - to prevent it from becoming a keyword while retaining the source line for analysis.

Generate and review

Select Generate Keywords. Review keyword chips, coverage counts, and highlighted matching lines; refine the input or rules and generate again as needed.
