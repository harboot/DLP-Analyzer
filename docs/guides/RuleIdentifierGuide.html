Policies Matcher Guide

Match alert violation triggers with policy classifiers.

Features

  • Combines multiple DLP alert CSV or XLSX exports and multiple extracted policy JSON files.
  • Matches alert violation triggers and policy names against policy-rule classifiers in a background worker.
  • Tracks processing with KPI cards and a log, groups matched rules by policy in the chart, shows policy totals when no rule matches, and exports alerts enriched with Rule Name.

Quick start

  1. Use Upload Policy (JSON) for one or more extracted policies containing policy.rules and classifier names. Use Upload DLP Alerts (CSV or XLSX) for one or more exports containing Violation Triggers and Policies. Each new selection replaces the previous files of that type.
  2. After both datasets are recognized, select Process in Worker. Follow progress in the KPI cards and log, then review the Alerts per Rule Name chart.

Missing-column warnings

Files that cannot be classified display a warning naming the expected columns that are absent. They are skipped; export them again with the required headers.

Download results

When processing finishes, use Download CSV to save the alerts enriched with Rule Name. Processing remains in your browser.
