Rule Identifier Guide

Match alert violation triggers with policy classifiers.

Quick start

  1. Upload at least one Alerts CSV containing Violation Triggers and Policies, and one Policies CSV containing Rule Name, Relation, and Classifiers. Files and folders can be selected together.
  2. After both datasets are recognized, select Process in Worker. Follow progress in the KPI cards and log, then review the Alerts per Rule Name chart.

Missing-column warnings

Files that cannot be classified display a warning naming the expected columns that are absent. They are skipped; export them again with the required headers.

Download results

When processing finishes, use Download CSV to save the alerts enriched with Rule Name. Processing remains in your browser.
