Alert Analyzer Guide

Analyze DLP alert exports and investigate activity in interactive views.

Quick start

  1. Export CSV or XLSX data with these columns: ID, Incident Time, Event Time, Source, Policies, Destination, File Name, Transaction Size (KB), Details, Status, Channel, Action, and Severity. You may select multiple files; their rows are combined.
  2. Drop files onto the upload area or select them. Use the Overview and alert tabs to review summaries, channels, blocked activity, filters, charts, and risk findings.

Missing-column warnings

After an upload, a warning lists each file that omits an expected column. The analyzer keeps loading available data, but views and rules that depend on a missing value may be incomplete. Correct the export and upload it again.

Export and privacy

Use the available table actions to filter, copy, or export results. File processing occurs locally in your browser.
