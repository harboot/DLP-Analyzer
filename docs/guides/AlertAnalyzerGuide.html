Alert Analyzer Guide

Analyze DLP alert exports and investigate activity in interactive views.

Features

  • Combines multiple CSV files or the first worksheet from each XLSX workbook into one local analysis.
  • Builds an overview plus individual alert tabs with summaries, channel and blocked-activity breakdowns, interactive filters, and charts.
  • Shows a concise, consistent alert table while each row copy and CSV export retains every original alert field.
  • Evaluates extensible JSON rule packs to highlight risk findings.

Quick start

  1. Export CSV or XLSX data with these columns: ID, Incident Time, Event Time, Source, Policies, Destination, File Name, Transaction Size (KB), Details, Status, Channel, Action, and Severity. You may select multiple files; their rows are combined.
  2. Drop files onto the upload area or select them. Use the Overview and alert tabs to review summaries, channels, blocked activity, filters, charts, and risk findings. Tables initially show 10 rows and include pagination.

Missing-column warnings

After an upload, a warning lists the expected columns omitted by the uploaded files. The analyzer keeps loading available data, but views and rules that depend on a missing value may be incomplete. Correct the export and upload it again.

Ignored sources and destinations

Open the settings button beside the page title to exclude alerts from every view and count. Enter source or destination values separated by commas or new lines. Use an asterisk (*) to match any characters, such as src-rep* or *.example.com, then save the settings. Saved exclusions remain available in this browser.

Copy, export, and privacy

The Copy control on each alert includes all uploaded columns, not only the columns visible in the table. Export CSV saves all filtered rows and all original columns. File processing occurs locally in your browser.
