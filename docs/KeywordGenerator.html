Two analysis modes are available: Document Subject and Document Content.
Email Subject: uses a greedy set-cover algorithm to find the most efficient keywords.
Email Content: scores candidate phrases based on frequency, length, and context.
Start a rule with + for must-use (always include). Start with - for contain-ban (exclude the phrase, but still process the line).
